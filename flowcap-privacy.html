FlowCap

개인정보 처리방침

최종 업데이트: 2026년 8월 7일

개발자는 별도의 사용자 계정이나 서버를 운영하지 않으며, 이름, 이메일, 전화번호, 결제 정보 등을 직접 수집하지 않습니다. 위치, 연락처, 사진, 카메라에도 접근하지 않습니다. 마이크(또는 맥의 경우 시스템 오디오)로 들어오는 소리는 Apple의 온디바이스(기기 내부) 음성인식 프레임워크로만 처리되며, 자체 분석 및 광고 SDK와 자체 서버 전송도 없습니다.

1. 개발자가 직접 수집하는 개인정보

개발자는 앱을 통해 이용자의 이름, 이메일 주소, 전화번호, 연락처, 위치, 사진, 결제 정보 등을 직접 수집하거나 저장하지 않습니다. 회원가입이나 로그인 절차가 없으며, 앱에는 개발자가 운영하는 광고 또는 분석 SDK가 포함되어 있지 않습니다.

2. 마이크 및 음성 데이터

앱은 스피커(iOS 버전) 또는 시스템 오디오(맥 버전)로 재생되는 영어 음성을 실시간 자막으로 변환하기 위해 마이크 또는 시스템 오디오에 접근합니다. 이 음성은 Apple의 온디바이스 음성인식 프레임워크로만 처리되며, 오디오 원본은 저장되지 않고 개발자의 서버나 그 어떤 서버로도 전송되지 않습니다.

마이크(또는 백그라운드 오디오 처리)는 이용자가 앱에서 직접 "듣기 시작"을 누른 경우에만 작동하며, "듣기 종료"를 누르거나 앱을 완전히 종료하면 즉시 중단됩니다. 이용자의 명시적인 시작 없이 백그라운드에서 임의로 청취를 시작하지 않습니다.

3. 자막(전사) 텍스트

인식된 자막 텍스트는 앱 메모리에만 보관되며, 별도의 서버나 클라우드에 저장되지 않습니다. "지우기"를 누르거나 앱을 완전히 종료하면 사라집니다.

다이내믹 아일랜드 및 잠금 화면(라이브 액티비티)에 표시되는 자막도 Apple의 ActivityKit을 통해 기기 내부에서만 처리되며 외부로 전송되지 않습니다.

4. "GPT 자막번역" 기능과 외부 서비스

앱에는 인식된 자막을 번역해주는 선택적 기능이 있습니다. 이 버튼을 누르면 전사된 텍스트가 클립보드에 복사되고 iOS/macOS의 단축어(Shortcuts) 앱이 열립니다. 이 단축어는 FlowCap이 자동으로 설치하는 것이 아니라, 개발자가 제공하는 iCloud 링크를 통해 이용자가 직접 설치하는 별도의 자동화입니다.

개발자가 제공하는 기본 단축어를 그대로 사용하는 경우, 복사된 텍스트는 번역을 위해 OpenAI(ChatGPT)로 전송됩니다. 이 과정은 이용자의 단축어 앱을 통해 이루어지며, FlowCap은 이 과정에 직접 관여하거나 전송되는 데이터를 확인할 수 없습니다. 전송 이후의 처리에는 OpenAI의 개인정보처리방침이 적용됩니다.
OpenAI 개인정보처리방침: https://openai.com/privacy/

이 기능은 완전히 선택 사항이며, 버튼을 누르지 않으면 어떠한 데이터도 OpenAI로 전송되지 않습니다. 이용자가 단축어를 직접 수정하거나 다른 단축어로 교체해 사용하는 경우, 데이터가 어디로 전송되는지는 해당 단축어의 구성에 따라 달라지며 이는 FlowCap이 통제할 수 없는 영역입니다. 번역 결과 역시 앱 메모리에만 임시로 표시되며 별도로 저장되지 않습니다.

5. 분석, 추적 및 제3자 공유

앱에는 애널리틱스, 크래시 리포팅, 광고 SDK가 전혀 포함되어 있지 않습니다. 위 4번의 선택적 번역 기능을 제외하고는 어떠한 제3자와도 데이터를 공유하지 않습니다.

6. 보관 기간과 삭제

자막 텍스트는 이용자가 "지우기"를 누르거나 앱을 종료하는 즉시 삭제됩니다. 개발자는 별도의 서버에 이용자의 음성이나 자막 데이터를 저장하지 않으므로, 개발자에게 서버 데이터 삭제를 요청하실 필요가 없습니다.

7. 아동의 개인정보

이 앱은 개인정보 자체를 수집하지 않으며, 만 13세 미만 아동을 포함해 특정 이용자를 대상으로 개인정보를 수집하지 않습니다.

Privacy Policy

Last updated: August 7, 2026

The developer does not operate a separate user account system or server, and does not directly collect names, email addresses, phone numbers, or payment information. The app does not access location, contacts, photos, or camera. Sound captured through the microphone (or system audio on Mac) is processed only by Apple's on-device speech recognition framework, and the app contains no in-house analytics or advertising SDKs and does not transmit data to any developer-operated server.

1. Personal Information Collected Directly by the Developer

The developer does not directly collect or store users' names, email addresses, phone numbers, contacts, location, photos, or payment information through the app. There is no sign-up or login process, and the app does not include any advertising or analytics SDK operated by the developer.

2. Microphone and Voice Data

The app accesses the microphone (iOS) or system audio (Mac) in order to convert English speech played through the speaker or currently playing on the Mac into real-time captions. This audio is processed solely by Apple's on-device speech recognition framework; the original audio is never stored and is never transmitted to the developer's server or any other server.

The microphone (or background audio processing) is only active while the user has explicitly tapped "Start Listening" in the app, and stops immediately when the user taps "Stop" or fully quits the app. The app never starts listening in the background without the user's explicit action.

3. Caption (Transcript) Text

Recognized caption text is kept only in the app's memory and is never stored on any server or in the cloud. It is cleared when the user taps "Clear" or fully quits the app.

Captions shown in the Dynamic Island and on the Lock Screen (Live Activity) are also processed entirely on-device via Apple's ActivityKit and are never transmitted externally.

4. The "GPT Translation" Feature and External Services

The app includes an optional feature that translates recognized captions. Tapping this button copies the transcribed text to the clipboard and opens the iOS/macOS Shortcuts app. This Shortcut is not automatically installed by FlowCap — it is a separate automation that the user installs themselves via an iCloud link provided by the developer.

If the user uses the default Shortcut provided by the developer as is, the copied text is sent to OpenAI (ChatGPT) for translation. This happens through the user's own Shortcuts app; FlowCap is not directly involved in this process and cannot see the data being transmitted. Once the data leaves via the Shortcut, OpenAI's own privacy policy applies.
OpenAI Privacy Policy: https://openai.com/privacy/

This feature is entirely optional — no data is sent to OpenAI unless the user taps this button. If the user modifies the Shortcut or substitutes a different one, where the data is sent depends entirely on that Shortcut's own configuration, which is outside FlowCap's control. The translation result is likewise shown only temporarily in the app's memory and is not separately stored.

5. Analytics, Tracking, and Third-Party Sharing

The app contains no analytics, crash reporting, or advertising SDKs. Other than the optional translation feature described in Section 4, the app does not share data with any third party.

6. Retention and Deletion

Caption text is deleted immediately when the user taps "Clear" or quits the app. Because the developer does not store users' voice or caption data on any server, there is no need to request server-side data deletion from the developer.

7. Children's Privacy

This app does not collect personal information at all, and does not knowingly collect personal information from any specific group of users, including children under the age of 13.
