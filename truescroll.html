자동 전환 작동 중메뉴 막대에서 조용히 실행됩니다.

How it works

손에 닿는 장치에 맞는 방향

macOS의 자연스러운 스크롤은 그대로 유지합니다. TrueScroll은 마우스 휠 입력만 구분해 익숙한 방향으로 바꿉니다.

트랙패드

↕

자연스러운 스크롤 유지

콘텐츠를 직접 밀어 움직이는 macOS 방식 그대로 사용합니다.

마우스

⇅

휠 방향만 자동 반전

일반 마우스에서 익숙한 스크롤 방향으로 즉시 바뀝니다.

Simple by design

필요한 순간에만 보이는 간결한 메뉴

상태 확인과 주요 옵션은 메뉴 막대 아이콘 하나에 모았습니다. 설정 창을 계속 열어둘 필요가 없습니다.

Features

켜두면, 나머지는 자동으로

입력 장치를 바꿀 때마다 시스템 설정을 찾아갈 필요 없이 스크롤 흐름을 일관되게 유지합니다.

↕

자동 장치 구분

트랙패드 스크롤은 그대로 통과시키고, 마우스 휠 입력만 반전합니다.

⌁

부드러운 휠 호환

Logitech 등 고해상도 휠을 위한 호환 모드를 메뉴에서 켤 수 있습니다.

◉

로그인 시 자동 실행

Mac을 켜면 자동으로 시작해 메뉴 막대에서 조용히 동작합니다.

Privacy

스크롤 외에는 보지 않습니다

TrueScroll은 스크롤 방향을 바꾸기 위해 손쉬운 사용 권한을 사용합니다. 키 입력, 클릭 대상, 화면 내용은 읽지 않으며 분석이나 네트워크 통신 기능도 없습니다.

  • ✓키보드 입력 수집 없음
  • ✓화면 및 파일 접근 없음
  • ✓분석 및 네트워크 전송 없음

Getting started

세 단계면 충분합니다

  • macOS 14 Sonoma 이상
  • Apple Silicon Mac
  • 손쉬운 사용 권한 필요
  1. 다운로드하고 응용 프로그램으로 이동 압축을 푼 TrueScroll을 응용 프로그램 폴더로 옮깁니다.
  2. 손쉬운 사용 권한 허용 첫 실행 안내에 따라 시스템 설정에서 TrueScroll을 허용합니다.
  3. 자연스러운 스크롤 켜기 macOS 자연스러운 스크롤을 켜두면 TrueScroll이 나머지를 처리합니다.
