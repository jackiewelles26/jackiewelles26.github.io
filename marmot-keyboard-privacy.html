마멋 키보드

개인정보 처리방침

시행일: 2026년 8월 12일

1. 개인정보 수집 여부

마멋 키보드는 이름, 이메일 주소, 연락처, 위치, 기기 식별자, 입력 내용 또는 그 밖의 개인정보를 수집하지 않습니다. 계정 가입, 광고 및 이용 분석 기능도 제공하지 않습니다.

2. 키보드 입력 내용

사용자가 입력한 글자는 기기 안의 키보드 확장에서 처리되어 iOS가 제공하는 입력 통로를 통해 현재 사용 중인 앱의 입력란으로 전달됩니다. 입력 내용은 개발자에게 전송되지 않으며, 앱 또는 공유 저장소에 기록·보관되지 않고 광고, 분석 또는 프로파일링에 사용되지 않습니다.

3. 기기에 저장되는 설정

키 소리 모드, 진동 사용 여부, 스페이스 연타 설정과 전체 접근 허용 확인 상태만 앱과 키보드 확장이 사용하는 기기 내 공유 저장소에 저장됩니다. 이 설정은 외부 서버로 전송되지 않습니다.

4. 전체 접근 허용

전체 접근 허용은 선택 사항입니다. 허용하지 않아도 글자 입력과 기본 클릭음은 전부 동작합니다.

허용한 경우에도 마멋 키보드는 이를 진동 피드백 사용과 호스트 앱·키보드 확장 사이의 로컬 설정 공유에만 사용하며, 입력 내용이나 개인정보를 네트워크로 전송하지 않습니다.

5. 제3자 제공 및 외부 서비스

마멋 키보드는 개인정보를 제3자에게 판매하거나 제공하지 않으며, 광고 또는 제3자 분석 SDK를 포함하지 않습니다. 한글 조합에 사용되는 libhangul은 앱에 포함되어 기기 안에서만 실행되고 데이터를 전송하지 않습니다. App Store와 iOS 자체에서 처리하는 정보에는 Apple의 개인정보 보호정책이 적용됩니다.
Apple 개인정보 보호정책: https://www.apple.com/legal/privacy/

6. 보관 및 삭제

키보드 입력 내용은 보관하지 않습니다. 로컬 설정은 사용자가 설정을 변경하거나 앱을 삭제할 때까지 기기에 남을 수 있습니다. 서버에 저장되는 사용자 데이터가 없으므로 별도의 서버 데이터 삭제 요청은 필요하지 않습니다.

7. 처리방침 변경

앱의 기능 또는 데이터 처리 방식이 바뀌면 이 처리방침과 App Store의 개인정보 공개 내용을 함께 갱신하고 시행일을 변경합니다.

Marmot Keyboard

Privacy Policy

Effective date: August 12, 2026

1. Information Collected

Marmot Keyboard does not collect names, email addresses, contacts, location, device identifiers, typed content, or any other personal information. It provides no account registration, advertising, or usage analytics.

2. Keyboard Input

Characters you type are processed by the keyboard extension on your device and delivered to the text field of the app you are currently using through the input channel provided by iOS. Your input is not transmitted to the developer, is not recorded or retained in the app or in shared storage, and is not used for advertising, analytics, or profiling.

3. Settings Stored on the Device

Only the key sound mode, whether haptic feedback is enabled, the consecutive-space setting, and the confirmed state of Full Access are stored in the on-device shared storage used by the app and the keyboard extension. These settings are not transmitted to any external server.

4. Full Access

Full Access is optional. Typing and the basic click sound work fully without it.

Even when it is granted, Marmot Keyboard uses it only for haptic feedback and for sharing local settings between the host app and the keyboard extension. It does not transmit your input or any personal information over the network.

5. Third Parties and External Services

Marmot Keyboard does not sell or provide personal information to third parties, and contains no advertising or third-party analytics SDKs. libhangul, used for Hangul composition, is bundled with the app, runs entirely on the device, and transmits no data. Information handled by the App Store and by iOS itself is governed by Apple's privacy policy.
Apple Privacy Policy: https://www.apple.com/legal/privacy/

6. Retention and Deletion

Keyboard input is not retained. Local settings may remain on the device until the user changes them or deletes the app. Because no user data is stored on any server, there is no need to request server-side data deletion.

7. Changes to This Policy

If the app's features or data handling change, this policy and the privacy disclosures on the App Store will be updated together and the effective date revised.
